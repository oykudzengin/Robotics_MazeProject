# Differential Drive Robot Maze Project, 2025 Summer Semester, Technische Universitat Berlin
## Robotics: Fundamentals Course from TU Berlin
## Instructor: Prof. Dr. Oliver Brock, TU Berlin
## Assistant: Furkan Davulcu, TU Berlin

### Summary
Understanding fundamentals of robotics concepts. Line detection, motion planning, aligning, localization, path planning, data processing and control.
Introduction to ROS structure. <br>

### Progress of the Course
Through the semester, 4 different assignments were given for students to accomplish and work on final mission of the robot, which is completing the planned steps in the maze. <br>
1. Wandering Around The Maze
  To begin with, robot had to move around the maze freely without hitting the walls. Following a planned motion either processing encoder data or without any feedback from sensors. Aligning itself into any cell in the maze.
2. Executing a Particular Plan
   Given a plan to the robot, it should follow the directions and drive through the steps in the plan. Meanwhile determining whether the path plan is doable or not. Optimizing the motion type, smoother turns and faster driving on straight paths.
3. Mapping and Localization
   After mapping the physical maze environment for robot to know, it should return coordinates for its position in the maze which can be done by localizing. Next step would be the robot constantly tracking its position while executing a plan.
4. Path Planning
   Given a particular coordinate in the maze, the robot should come up with an optimal path to reach to the target cell.

## Final Task for the Robot to do
In the 6x6 maze, robot has gold-points and pick-up points, where it should garrive to the gold points and collect golds to earn more points for the race. After collecting golds, it should drive to a pick-up point
to get out from the maze. Each point type has different sound gets played when reached, for us the understand robot is following everything as told. <br> <br>
